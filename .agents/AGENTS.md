Codebase summary

- The main development mono-repo for Acquia Site Studio
  - containing
    - A Drupal module, a base Drupal theme, and Drupal sub-modules.
    - `apps/` A React application providing a custom UI for interacting with Site Studio features.
    - `cohesion-services/` A Node.js backend application (dx8-gateway) that serves as an API layer serving static assets and handling CSS and template compilation.
